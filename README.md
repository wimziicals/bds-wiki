# BDS Wiki

An unofficial community wiki for Minecraft: Bedrock Dedicated Server.

**Read it at https://wimziicals.github.io/bds-wiki/**

Every push to `main` rebuilds and publishes the site with GitHub Actions.

    npm install
    npm run dev     # local site
    npm run build   # static site in docs/.vitepress/dist

Found a mistake or want to help? See [How to contribute](https://wimziicals.github.io/bds-wiki/contribute/contributing). No coding needed to report a problem or fix a page.
