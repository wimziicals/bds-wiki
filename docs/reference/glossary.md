# Glossary

| Term | Meaning |
|---|---|
| BDS | Bedrock Dedicated Server |
| CGNAT | Provider-side NAT that prevents ordinary port forwarding |
| DTLS | Encryption for UDP-based communication |
| ICE | Finds a network path for WebRTC |
| NetherNet | Bedrock's WebRTC-based transport |
| Operator | Player with administrative permission |
| PEM | Text format commonly holding cryptographic keys |
| Preview | Beta release line; needs a matching client |
| RakNet | The deprecated Bedrock transport |
| SecretString | Script placeholder for a hidden secret |
| Server Identity | Key used to recognize a server across connections |
| Signaling | Exchange that sets up a WebRTC connection |
| System pack | Pack automatically loaded by BDS |
| Ticking area | Chunks simulated without a nearby player |
| XUID | Persistent Xbox user identifier |
