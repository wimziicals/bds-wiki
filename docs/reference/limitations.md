# Limitations

- **No RCON.** Use stdin or an outgoing script connection.
- **No official native plugin API.** Use add-ons and scripts.
- **No friend invitations like Realms.**
- **One active world per process.**
- **No SRV-based port lookup**, according to the Minecraft Wiki; players enter the port.
- **No Java-style heap setting.**
- **Ubuntu is the only officially supported Linux distribution.**
- **Beta scripting modules can break between updates.**
- **RakNet is deprecated** and clients require NetherNet on current releases.
- **Server Identity is not an approval system**; it only recognizes a key.
