# server.properties generator

Pick your settings and download a ready-to-use `server.properties` for BDS **1.26.66.1**. Changed settings are highlighted, and problems that would stop your server are shown before you download.

1. Stop your server.
2. Choose a starting point, or load your current file.
3. Change what you need, then **Download**.
4. Replace `server.properties` in your server folder with the new file and start the server.

Unsure about a setting? Leave it alone: the default is used. Each setting is explained on [server.properties](./server-properties) and [Hidden properties](./hidden-properties).
